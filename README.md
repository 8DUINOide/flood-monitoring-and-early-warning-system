# Flood Monitoring Simulator
A simple web-based simulator for visualizing flood risk and environmental monitoring using an interactive map.
Overview
This application provides a demonstration of a flood monitoring system with the following features:

Interactive map with clickable areas and markers
Simulated environmental data (water levels, rainfall)
Alert levels: Green (Safe), Yellow (Prepare), Red (Critical)
Terrain visualization including elevation and contours
Sidebar details for selected areas
Simulation controls: start, pause, reset, and speed adjustment
Filter by alert status

The simulation models progressive changes in conditions over time, with color-coded visuals on the map.

## How to Run
No server or installation required — runs locally in a browser.

Save the files:
index.html
data.js
script.js
styles.css

Open index.html in a modern web browser (Chrome, Firefox, etc.).
Use the menu to start the simulation and explore the map.

## Features

Click markers or list items to view details and zoom
Filter views by current status
Change basemaps (Outdoors, Streets, Satellite)
Location search functionality
Responsive design for desktop and mobile

## Future Enhancements
Designed as a prototype, it can be extended to integrate real-time data from sensors via API in future versions.
